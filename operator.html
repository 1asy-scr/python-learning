Materi 4: Operator Python

Operator merupakan salah satu konsep dasar dalam pemrograman Python. Operator memungkinkan kita melakukan perhitungan, membandingkan nilai, menggabungkan kondisi, serta mengolah berbagai jenis data. Pada materi ini, kamu akan mempelajari jenis-jenis operator Python beserta contoh penggunaannya.

Tujuan Pembelajaran Setelah mempelajari materi ini, kamu diharapkan mampu:
  1. Menjelaskan pengertian dan fungsi operator Python.
  2. Mengidentifikasi berbagai jenis operator Python.
  3. Menggunakan operator untuk melakukan perhitungan matematika.
  4. Menggunakan operator perbandingan dan logika.
  5. Menerapkan operator dalam program sederhana.

1. Apa Itu Operator Python?

Operator adalah simbol atau tanda khusus yang digunakan untuk melakukan operasi terhadap suatu nilai atau variabel dalam program.

Operator Python digunakan untuk berbagai keperluan, seperti:

  • Melakukan perhitungan matematika.
  • Membandingkan dua buah nilai.
  • Menggabungkan beberapa kondisi.
  • Memberikan atau mengubah nilai variabel.
  • Memeriksa keanggotaan suatu data.
  • Membandingkan identitas objek.

Contoh Sederhana

angka1 = 10
angka2 = 5
hasil = angka1 + angka2

print(hasil)
Hasil Output: 
15

Penjelasan:

  • angka1 dan angka2 merupakan variabel.
  • + merupakan operator penjumlahan.
  • hasil merupakan variabel yang menyimpan hasil operasi.
  • print() digunakan untuk menampilkan hasil operasi.

3. Operator Aritmatika (Arithmetic Operators)

Operator aritmatika adalah operator yang digunakan untuk melakukan perhitungan matematika, seperti penjumlahan, pengurangan, perkalian, dan pembagian.

Daftar Operator Aritmatika

Operator Nama Contoh Hasil
+ Penjumlahan 10 + 5 15
- Pengurangan 10 - 5 5
* Perkalian 10 * 5 50
/ Pembagian 10 / 5 2.0
% Modulus 10 % 3 1
** Pangkat 2 ** 3 8
// Pembagian bulat 10 // 3 3

Contoh Penggunaan Operator Aritmatika

a = 10
b = 3

print("Penjumlahan:", a + b)
print("Pengurangan:", a - b)
print("Perkalian:", a * b)
print("Pembagian:", a / b)
print("Modulus:", a % b)
print("Pangkat:", a ** b)
print("Pembagian Bulat:", a // b)
Hasil Output: 
Penjumlahan: 13
Pengurangan: 7
Perkalian: 30
Pembagian: 3.3333333333333335
Modulus: 1
Pangkat: 1000
Pembagian Bulat: 3

Penjelasan operator khusus:

  • % atau modulus digunakan untuk mendapatkan sisa hasil pembagian.
  • ** digunakan untuk menghitung perpangkatan.
  • // menghasilkan hasil pembagian yang dibulatkan ke bawah.
Contoh memahami modulus dan pembagian bulat Pada operasi 10 % 3, hasilnya adalah 1 karena 10 dibagi 3 menghasilkan sisa 1. Sementara itu, 10 // 3 menghasilkan 3 karena hasil pembagian dibulatkan ke bawah.

4. Operator Perbandingan (Comparison Operators)

Operator perbandingan digunakan untuk membandingkan dua buah nilai. Hasil dari operasi perbandingan adalah nilai Boolean, yaitu True atau False.

Operator Keterangan Contoh
== Sama dengan 10 == 10
!= Tidak sama dengan 10 != 5
> Lebih besar dari 10 > 5
< Lebih kecil dari 5 < 10
>= Lebih besar atau sama dengan 10 >= 10
<= Lebih kecil atau sama dengan 5 <= 10

Contoh Program

a = 10
b = 5

print(a == b)
print(a != b)
print(a > b)
print(a < b)
print(a >= b)
print(a <= b)
Hasil Output: 
False
True
True
False
True
False

Penjelasan:

  • a == b menghasilkan False karena 10 tidak sama dengan 5.
  • a != b menghasilkan True karena 10 berbeda dari 5.
  • a > b menghasilkan True karena 10 lebih besar dari 5.
  • a < b menghasilkan False karena 10 tidak lebih kecil dari 5.
  • a >= b menghasilkan True karena 10 lebih besar atau sama dengan 5.
  • a <= b menghasilkan False karena 10 tidak lebih kecil atau sama dengan 5.

5. Operator Logika (Logical Operators)

Operator logika digunakan untuk menggabungkan dua atau lebih kondisi dalam suatu program. Python memiliki tiga operator logika utama, yaitu and, or, dan not.

Operator Fungsi
and Bernilai True jika semua kondisi bernilai True.
or Bernilai True jika minimal satu kondisi bernilai True.
not Membalik nilai Boolean.

A. Operator AND

Operator and menghasilkan True jika kedua kondisi bernilai True. 

umur = 17
nilai = 85

hasil = umur >= 15 and nilai >= 75
print(hasil)
Hasil Output: 
True

Kedua kondisi terpenuhi: umur lebih dari atau sama dengan 15 dan nilai lebih dari atau sama dengan 75.

B. Operator OR

Operator or menghasilkan True jika setidaknya salah satu kondisi bernilai True. 

nilai = 90

hasil = nilai >= 75 or nilai == 100
print(hasil)
Hasil Output: 
True

C. Operator NOT

Operator not digunakan untuk membalik nilai Boolean. Jika nilai awalnya True, hasilnya menjadi False, begitu pula sebaliknya. 

aktif = True
print(not aktif)
Hasil Output: 
False

Tabel Kebenaran Operator Logika

A B A and B A or B
True True True True
True False False True
False True False True
False False False False
A not A
True False
False True

6. Operator Penugasan (Assignment Operators)

Operator penugasan digunakan untuk memberikan nilai atau memperbarui nilai pada suatu variabel.

Operator Contoh Setara dengan
= x = 10 Memberikan nilai 10
+= x += 5 x = x + 5
-= x -= 5 x = x - 5
*= x *= 5 x = x * 5
/= x /= 5 x = x / 5
//= x //= 5 x = x // 5
%= x %= 5 x = x % 5
**= x **= 2 x = x ** 2

Contoh Program

angka = 10

angka += 5
print(angka)

angka -= 3
print(angka)

angka *= 2
print(angka)
Hasil Output: 
15
12
24

Nilai variabel angka berubah secara bertahap. Awalnya 10, kemudian ditambah 5 menjadi 15, dikurangi 3 menjadi 12, dan dikalikan 2 menjadi 24.

7. Operator Keanggotaan (Membership Operators)

Operator keanggotaan digunakan untuk memeriksa apakah suatu nilai terdapat di dalam sebuah kumpulan data, seperti String, List, Tuple, atau Dictionary.

Python memiliki dua operator keanggotaan:

  • in untuk memeriksa apakah nilai terdapat dalam kumpulan data.
  • not in untuk memeriksa apakah nilai tidak terdapat dalam kumpulan data.

Contoh Menggunakan List

buah = ["Apel", "Jeruk", "Mangga"]

print("Apel" in buah)
print("Anggur" in buah)
print("Anggur" not in buah)
Hasil Output: 
True
False
True

Contoh Menggunakan String

kalimat = "Saya belajar Python"

print("Python" in kalimat)
print("Java" not in kalimat)
Hasil Output: 
True
True

Pada contoh tersebut, Python memeriksa apakah teks tertentu terdapat dalam kalimat yang disimpan pada variabel kalimat.

8. Operator Identitas (Identity Operators)

Operator identitas digunakan untuk memeriksa apakah dua variabel merujuk pada objek yang sama di dalam memori.

Python memiliki dua operator identitas:

  • is untuk memeriksa apakah dua variabel merujuk pada objek yang sama.
  • is not untuk memeriksa apakah dua variabel tidak merujuk pada objek yang sama.

Contoh Program

a = [1, 2, 3]
b = a
c = [1, 2, 3]

print(a is b)
print(a is c)
print(a == c)
print(a is not c)
Hasil Output: 
True
False
True
True

Penjelasan:

  • a is b bernilai True karena keduanya merujuk pada objek yang sama.
  • a is c bernilai False karena keduanya merupakan objek yang berbeda.
  • a == c bernilai True karena isi kedua List sama.
  • a is not c bernilai True karena objeknya berbeda.
Perbedaan penting: == dan is
  • == membandingkan kesamaan nilai.
  • is membandingkan identitas objek.
Jangan menggunakan is sebagai pengganti == untuk membandingkan nilai biasa.

9. Operator Bitwise (Bitwise Operators)

Operator bitwise digunakan untuk melakukan operasi pada bilangan dalam bentuk biner (binary). Operator ini bekerja pada setiap posisi bit dari bilangan bulat.

Operator bitwise lebih sering digunakan dalam pemrograman tingkat lanjut, tetapi penting untuk mengenal fungsi dasarnya.

Operator Nama Keterangan
& AND Operasi AND bit
| OR Operasi OR bit
^ XOR Operasi XOR bit
~ NOT Membalik bit
<< Left Shift Menggeser bit ke kiri
>> Right Shift Menggeser bit ke kanan

Contoh Program

a = 5
b = 3

print(a & b)
print(a | b)
print(a ^ b)
print(a << 1)
print(a >> 1)
Hasil Output: 
1
7
6
10
2

Penjelasan sederhana:

  • Angka 5 dalam biner adalah 0101.
  • Angka 3 dalam biner adalah 0011.
  • Operator bitwise melakukan operasi terhadap setiap posisi bit.

10. Prioritas Operator Python

Ketika terdapat beberapa operator dalam satu ekspresi, Python memiliki aturan prioritas untuk menentukan operasi mana yang dikerjakan terlebih dahulu.

Contoh

hasil = 10 + 5 * 2
print(hasil)
Hasil Output: 
20

Mengapa hasilnya 20, bukan 30? Karena perkalian memiliki prioritas lebih tinggi daripada penjumlahan. Dengan demikian, Python menghitung 5 * 2 terlebih dahulu, kemudian menambahkan hasilnya dengan 10.

Urutan Prioritas Umum Operator Python

Prioritas Operator
1 (tertinggi) ()
2 **
3 +x, -x, ~x
4 *, /, //, %
5 +, -
6 <<, >>
7 &, ^, |
8 Perbandingan, in, is
9 not
10 and
11 (terendah) or

Untuk memperjelas urutan operasi, kamu dapat menggunakan tanda kurung. 

hasil = (10 + 5) * 2
print(hasil)
Hasil Output: 
30
Tips Gunakan tanda kurung jika ekspresi memiliki beberapa operator. Selain membantu mengatur urutan perhitungan, tanda kurung juga membuat kode lebih mudah dibaca.

11. Praktik Langsung: Membuat Kalkulator Sederhana

Sekarang kita akan mencoba menggunakan operator Python untuk membuat program kalkulator sederhana. Program ini menggunakan operator aritmatika untuk menghitung dua bilangan.

Kode Program

# Program Kalkulator Sederhana

angka1 = 20
angka2 = 5

print("==========================")
print("     KALKULATOR PYTHON    ")
print("==========================")
print("Angka pertama:", angka1)
print("Angka kedua  :", angka2)
print("--------------------------")
print("Penjumlahan :", angka1 + angka2)
print("Pengurangan :", angka1 - angka2)
print("Perkalian   :", angka1 * angka2)
print("Pembagian   :", angka1 / angka2)
print("Modulus     :", angka1 % angka2)
print("Pangkat     :", angka1 ** angka2)
print("==========================")
Hasil Output: 
==========================
     KALKULATOR PYTHON
==========================
Angka pertama: 20
Angka kedua  : 5
--------------------------
Penjumlahan : 25
Pengurangan : 15
Perkalian   : 100
Pembagian   : 4.0
Modulus     : 0
Pangkat     : 3200000
==========================

Analisis Program

Program tersebut menggunakan beberapa operator aritmatika untuk melakukan perhitungan terhadap dua variabel, yaitu angka1 dan angka2.

Operasi Operator Perhitungan Hasil
Penjumlahan + 20 + 5 25
Pengurangan - 20 - 5 15
Perkalian * 20 * 5 100
Pembagian / 20 / 5 4.0
Modulus % 20 % 5 0
Pangkat ** 20 ** 5 3200000

Cobalah mengubah nilai angka1 dan angka2 untuk melihat bagaimana hasil perhitungannya berubah.

14. Kesimpulan

Operator merupakan bagian penting dalam bahasa pemrograman Python karena digunakan untuk melakukan berbagai operasi terhadap data dan variabel. Melalui operator, programmer dapat melakukan perhitungan matematika, membandingkan nilai, menggabungkan kondisi, memperbarui nilai variabel, memeriksa keanggotaan data, serta membandingkan identitas objek.

Python memiliki tujuh kelompok operator utama yang telah dipelajari, yaitu operator aritmatika, perbandingan, logika, penugasan, keanggotaan, identitas, dan bitwise. Setiap operator memiliki fungsi dan cara penggunaan yang berbeda. Pemahaman terhadap operator akan menjadi bekal penting untuk mempelajari materi berikutnya, khususnya percabangan dan perulangan.
