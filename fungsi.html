Materi 9: Fungsi (Function) dalam Python

Selamat datang di materi kesembilan! Pada materi ini kita akan mempelajari cara membuat dan menggunakan fungsi untuk menyusun program Python yang lebih terstruktur, efisien, dan mudah digunakan kembali.

Tujuan Pembelajaran Setelah mempelajari materi ini, kamu diharapkan mampu:
  1. Menjelaskan pengertian dan manfaat fungsi dalam Python.
  2. Membuat dan memanggil fungsi menggunakan def.
  3. Menggunakan parameter, argumen, dan return.
  4. Membedakan built-in function, user-defined function, dan lambda.
  5. Menggunakan parameter default dan keyword argument.
  6. Memahami variabel lokal dan global.
  7. Membuat program sederhana dengan memanfaatkan fungsi.

1. Pengertian Fungsi dalam Python

Fungsi (function) adalah sekumpulan kode program yang dibuat untuk menjalankan tugas tertentu. Fungsi dapat digunakan berulang kali tanpa harus menulis ulang kode yang sama.

Dengan menggunakan fungsi, program Python menjadi lebih:

  • Terstruktur: Kode tersusun berdasarkan tugas masing-masing.
  • Efisien: Kode yang sama tidak perlu ditulis berulang kali.
  • Mudah diperbaiki: Kesalahan dapat diperbaiki pada bagian fungsi terkait.
  • Mudah dikembangkan: Fungsi dapat digunakan dalam berbagai bagian program.

Contoh tanpa menggunakan fungsi

print("Selamat datang!")
print("Selamat datang!")
print("Selamat datang!")

Contoh menggunakan fungsi

def salam():
    print("Selamat datang!")

salam()
salam()
salam()
Hasil Output: 
Selamat datang!
Selamat datang!
Selamat datang!

Kedua contoh menghasilkan output yang sama. Namun, menggunakan fungsi membuat kode lebih ringkas dan mudah dikelola. Kita cukup membuat fungsi satu kali, kemudian memanggilnya setiap kali diperlukan.

2. Cara Membuat Fungsi di Python

Untuk membuat fungsi, Python menggunakan kata kunci def. Berikut struktur dasar penulisan fungsi: 

def nama_fungsi():
    # Kode yang akan dijalankan
    perintah

Keterangan setiap bagian:

  • def: Kata kunci untuk mendefinisikan fungsi.
  • nama_fungsi: Nama yang digunakan untuk memanggil fungsi.
  • (): Tempat menuliskan parameter jika diperlukan.
  • :: Menandakan awal blok fungsi.
  • Indentasi: Menandakan kode yang termasuk dalam fungsi.

Contoh membuat fungsi

def perkenalan():
    print("Halo, nama saya Andi.")
    print("Saya sedang belajar Python.")

perkenalan()
Hasil Output: 
Halo, nama saya Andi.
Saya sedang belajar Python.
Hal penting! Fungsi yang sudah dibuat tidak otomatis dijalankan. Kita harus memanggilnya menggunakan nama fungsi diikuti tanda kurung ().

3. Fungsi dengan Parameter

Parameter adalah variabel yang ditulis di dalam tanda kurung saat mendefinisikan fungsi. Parameter digunakan untuk menerima data dari luar fungsi.

Contoh fungsi dengan satu parameter

def salam(nama):
    print("Halo,", nama)
    print("Selamat belajar Python!")

salam("Andi")
salam("Budi")
salam("Siti")
Hasil Output: 
Halo, Andi
Selamat belajar Python!
Halo, Budi
Selamat belajar Python!
Halo, Siti
Selamat belajar Python!

Pada contoh tersebut:

  • nama merupakan parameter.
  • "Andi", "Budi", dan "Siti" merupakan argumen atau nilai yang dikirimkan ketika fungsi dipanggil.

Fungsi dengan lebih dari satu parameter

Sebuah fungsi juga dapat menerima beberapa parameter. Setiap parameter dipisahkan dengan tanda koma. 

def perkenalan(nama, umur):
    print("Nama:", nama)
    print("Umur:", umur, "tahun")

perkenalan("Andi", 17)
Hasil Output: 
Nama: Andi
Umur: 17 tahun
Ingat! Parameter adalah variabel pada definisi fungsi, sedangkan argumen adalah nilai yang diberikan ketika fungsi dipanggil.

4. Fungsi dengan Return

Selain menampilkan hasil menggunakan print(), fungsi dapat mengembalikan nilai menggunakan perintah return.

Nilai yang dikembalikan dapat disimpan dalam variabel atau digunakan dalam perhitungan lain.

Contoh penggunaan return

def tambah(a, b):
    hasil = a + b
    return hasil

total = tambah(10, 5)
print("Hasil penjumlahan:", total)
Hasil Output: 
Hasil penjumlahan: 15

Perbedaan print() dan return

print() return
Menampilkan informasi ke layar. Mengembalikan nilai dari fungsi.
Tidak mengirimkan hasil sebagai nilai fungsi. Hasilnya dapat disimpan dalam variabel.
Cocok untuk menampilkan pesan. Cocok untuk pengolahan data dan perhitungan.

Contoh perbandingan

def contoh_print():
    print(10 + 5)

def contoh_return():
    return 10 + 5

contoh_print()

hasil = contoh_return()
print("Nilai return:", hasil)
Hasil Output: 
15
Nilai return: 15

Fungsi contoh_print() langsung menampilkan hasil ke layar. Sementara itu, contoh_return() mengembalikan nilai 15 sehingga hasilnya dapat disimpan dalam variabel hasil.

5. Jenis-Jenis Fungsi dalam Python

Secara umum, fungsi dalam Python dapat dibedakan menjadi beberapa jenis berdasarkan cara pembuatannya.

A. Built-in Function

Built-in function adalah fungsi bawaan Python yang dapat langsung digunakan tanpa perlu mendefinisikannya terlebih dahulu. 

nama = "Python"
angka = [10, 20, 30, 40]

print(len(nama))
print(max(angka))
print(min(angka))
print(sum(angka))
Hasil Output: 
6
40
10
100

Beberapa fungsi bawaan Python yang sering digunakan:

Fungsi Kegunaan
print() Menampilkan informasi.
input() Menerima masukan pengguna.
len() Menghitung jumlah elemen.
type() Mengetahui tipe data.
max() Mencari nilai terbesar.
min() Mencari nilai terkecil.
sum() Menjumlahkan elemen angka.
range() Membuat urutan bilangan.

B. User-defined Function

User-defined function adalah fungsi yang dibuat sendiri oleh programmer menggunakan kata kunci def. 

def hitung_luas_persegi(sisi):
    return sisi * sisi

luas = hitung_luas_persegi(5)
print("Luas persegi:", luas)
Hasil Output: 
Luas persegi: 25

C. Anonymous Function (Lambda)

Lambda adalah fungsi sederhana yang dibuat tanpa menggunakan nama fungsi seperti def. Lambda umumnya digunakan untuk operasi sederhana yang dapat ditulis dalam satu ekspresi.

Struktur penulisan lambda:

lambda parameter: ekspresi

Contoh penggunaan lambda

kuadrat = lambda x: x * x

print(kuadrat(5))
print(kuadrat(8))
Hasil Output: 
25
64
Kesimpulan singkat: Built-in function merupakan fungsi bawaan Python, user-defined function dibuat sendiri menggunakan def, sedangkan lambda digunakan untuk membuat fungsi sederhana secara ringkas.

6. Parameter Default

Parameter default adalah parameter yang sudah memiliki nilai awal. Jika pengguna tidak memberikan argumen untuk parameter tersebut, Python akan menggunakan nilai default.

Contoh penggunaan parameter default

def salam(nama="Pengunjung"):
    print("Halo,", nama)

salam()
salam("Andi")
Hasil Output: 
Halo, Pengunjung
Halo, Andi

Pada contoh tersebut, "Pengunjung" menjadi nilai default untuk parameter nama. Ketika fungsi dipanggil tanpa argumen, nilai tersebut digunakan secara otomatis.

7. Keyword Argument

Keyword argument adalah cara mengirimkan argumen dengan menyebutkan nama parameternya. Dengan cara ini, argumen tidak harus ditulis sesuai urutan parameter.

Contoh penggunaan keyword argument

def biodata(nama, umur, kota):
    print("Nama:", nama)
    print("Umur:", umur)
    print("Kota:", kota)

biodata(
    kota="Jakarta",
    nama="Andi",
    umur=17
)
Hasil Output: 
Nama: Andi
Umur: 17
Kota: Jakarta

Keuntungan keyword argument adalah kita dapat menuliskan argumen tanpa harus mengikuti urutan parameter, selama nama parameternya sesuai.

Catatan: Keyword argument harus menggunakan nama parameter yang benar. Jangan menuliskan argumen posisi setelah keyword argument dalam pemanggilan fungsi.

8. Variabel Lokal dan Variabel Global

Dalam fungsi, terdapat dua jenis variabel yang perlu dipahami berdasarkan ruang lingkup penggunaannya (scope).

A. Variabel Lokal

Variabel lokal adalah variabel yang dibuat di dalam fungsi dan hanya dapat digunakan di dalam fungsi tersebut. 

def belajar():
    pesan = "Saya sedang belajar Python"
    print(pesan)

belajar()
Hasil Output: 
Saya sedang belajar Python

Variabel pesan merupakan variabel lokal karena dibuat di dalam fungsi belajar().

B. Variabel Global

Variabel global adalah variabel yang dibuat di luar fungsi sehingga dapat diakses dari berbagai bagian program. 

nama = "Andi"

def tampilkan_nama():
    print("Nama:", nama)

tampilkan_nama()
Hasil Output: 
Nama: Andi
Catatan penting: Jika ingin mengubah variabel global dari dalam fungsi, Python menyediakan kata kunci global. Namun, sebaiknya gunakan parameter dan return jika memungkinkan agar kode lebih mudah dipahami dan dikelola.

Contoh penggunaan global

jumlah = 0

def tambah_jumlah():
    global jumlah
    jumlah += 1

tambah_jumlah()
tambah_jumlah()

print(jumlah)
Hasil Output: 
2

9. Contoh Project: Program Kalkulator Sederhana

Sekarang kita akan membuat program kalkulator sederhana dengan memanfaatkan beberapa fungsi. Setiap operasi matematika akan dibuat dalam fungsi tersendiri.

Kode Program

def tambah(a, b):
    return a + b

def kurang(a, b):
    return a - b

def kali(a, b):
    return a * b

def bagi(a, b):
    if b == 0:
        return "Tidak bisa dibagi nol"
    return a / b

# Memanggil fungsi
print("=== KALKULATOR SEDERHANA ===")

angka1 = float(input("Masukkan angka pertama: "))
angka2 = float(input("Masukkan angka kedua: "))

print("Hasil tambah:", tambah(angka1, angka2))
print("Hasil kurang:", kurang(angka1, angka2))
print("Hasil kali:", kali(angka1, angka2))
print("Hasil bagi:", bagi(angka1, angka2))
Hasil Output: 
=== KALKULATOR SEDERHANA ===
Masukkan angka pertama: 10
Masukkan angka kedua: 5
Hasil tambah: 15.0
Hasil kurang: 5.0
Hasil kali: 50.0
Hasil bagi: 2.0

Penjelasan Program

  1. Fungsi tambah() digunakan untuk menjumlahkan dua angka.
  2. Fungsi kurang() digunakan untuk mengurangi dua angka.
  3. Fungsi kali() digunakan untuk mengalikan dua angka.
  4. Fungsi bagi() digunakan untuk membagi dua angka.
  5. Setiap fungsi mengembalikan hasil menggunakan return.
  6. Program memeriksa apakah angka pembagi bernilai nol agar tidak terjadi pembagian dengan nol.

10. Kesalahan Umum Saat Menggunakan Fungsi

Ketika belajar menggunakan fungsi, pemula sering melakukan beberapa kesalahan berikut.

Kesalahan Penyebab Solusi
NameError Nama fungsi tidak ditemukan. Periksa nama fungsi dan pastikan fungsi sudah didefinisikan.
TypeError Jumlah atau tipe argumen tidak sesuai. Periksa parameter dan argumen.
IndentationError Indentasi tidak tepat. Gunakan indentasi secara konsisten.
Fungsi tidak berjalan Fungsi belum dipanggil. Panggil fungsi dengan tanda ().
Hasil fungsi None Tidak ada nilai yang dikembalikan. Gunakan return jika membutuhkan hasil.

Contoh kesalahan: jumlah argumen tidak sesuai

def tambah(a, b):
    return a + b

print(tambah(10))

Kode tersebut menghasilkan TypeError karena fungsi membutuhkan dua argumen, tetapi hanya menerima satu argumen.

Perbaikannya:

def tambah(a, b):
    return a + b

print(tambah(10, 5))
Hasil Output: 
15

13. Kesimpulan

Pada materi ini, kita telah mempelajari berbagai konsep penting tentang fungsi Python:

  1. Fungsi dibuat menggunakan kata kunci def.
  2. Fungsi dipanggil dengan menuliskan nama fungsi diikuti ().
  3. Parameter digunakan untuk menerima data dari luar fungsi.
  4. return digunakan untuk mengembalikan nilai.
  5. Python memiliki fungsi bawaan atau built-in function.
  6. Lambda merupakan fungsi anonim untuk operasi sederhana.
  7. Variabel lokal dan global memiliki ruang lingkup berbeda.
  8. Penerapan fungsi dalam kalkulator sederhana.
Poin Penting: Dengan memahami fungsi, kamu sudah memiliki dasar penting untuk membuat program Python yang lebih kompleks. Biasakan membagi program menjadi fungsi-fungsi kecil agar kode lebih mudah dibaca, diuji, dan dikembangkan.
