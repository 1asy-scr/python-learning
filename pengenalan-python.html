Materi 1: Pengenalan Python

Selamat datang di materi pertama Python Learn! Pada materi ini, kamu akan mengenal bahasa pemrograman Python, sejarah perkembangannya, berbagai kegunaannya dalam dunia teknologi, serta aturan dasar penulisan kode Python.

Tujuan Pembelajaran Setelah mempelajari materi ini, kamu diharapkan mampu:
  1. Menjelaskan pengertian dan sejarah singkat Python.
  2. Mengidentifikasi keunggulan dan kegunaan Python.
  3. Memahami persiapan untuk mulai belajar Python.
  4. Menulis dan menjalankan program Python sederhana.
  5. Memahami aturan dasar penulisan kode Python.

1. Apa Itu Python?

Python adalah bahasa pemrograman tingkat tinggi (high-level programming language) yang dirancang agar mudah dibaca, dipelajari, dan digunakan.

Python pertama kali dikembangkan oleh Guido van Rossum dan dirilis pada tahun 1991. Python menjadi salah satu bahasa pemrograman populer karena memiliki sintaks yang sederhana serta dapat digunakan untuk berbagai kebutuhan pengembangan teknologi.

Python dapat digunakan untuk membuat aplikasi, mengembangkan website, mengolah data, membuat kecerdasan buatan (Artificial Intelligence), hingga mengotomatisasi pekerjaan.

Contoh kode Python sederhana:

print("Hello, World!")

Hasil output:

Hello, World!

Kode tersebut merupakan contoh program sederhana yang digunakan untuk menampilkan tulisan ke layar. Perintah print() akan dibahas lebih lanjut pada bagian berikutnya.

2. Sejarah Singkat Python

Python dikembangkan oleh Guido van Rossum pada akhir tahun 1980-an dan pertama kali dirilis pada tahun 1991. Nama Python terinspirasi dari acara komedi Inggris bernama Monty Python's Flying Circus, bukan dari nama ular piton.

Seiring perkembangannya, Python terus mengalami pembaruan dan menjadi bahasa pemrograman yang digunakan secara luas di berbagai bidang teknologi.

Beberapa versi Python yang penting:

Versi Tahun Keterangan
Python 1.0 1994 Rilis versi utama pertama.
Python 2.0 2000 Memperkenalkan berbagai fitur baru.
Python 3.0 2008 Pembaruan besar bahasa Python.
Python 3.x Berlanjut Pengembangan dan pembaruan berkelanjutan.
Fakta Menarik Nama Python bukan berasal dari nama ular, melainkan dari acara komedi Inggris yang disukai oleh penciptanya.

3. Mengapa Harus Belajar Python?

Python merupakan pilihan yang bagus untuk pemula karena memiliki beberapa keunggulan berikut.

1. Mudah Dipelajari

Sintaks Python sederhana dan mudah dibaca, sehingga cocok untuk orang yang baru mengenal pemrograman.

2. Serbaguna

Python dapat digunakan untuk pengembangan website, aplikasi, analisis data, kecerdasan buatan, dan otomatisasi.

3. Gratis dan Open Source

Python dapat digunakan secara gratis dan kode sumbernya tersedia untuk dipelajari serta dikembangkan.

4. Komunitas Besar

Banyak programmer menggunakan Python sehingga tersedia banyak tutorial, dokumentasi, forum diskusi, dan pustaka pendukung.

4. Kegunaan Python dalam Dunia Teknologi

Python memiliki banyak kegunaan dalam berbagai bidang. Berikut beberapa contoh penerapannya.

Web Development

Membangun aplikasi dan website menggunakan framework seperti Django dan Flask.

Artificial Intelligence

Mengembangkan sistem kecerdasan buatan dan machine learning.

Data Science

Mengolah, menganalisis, dan memvisualisasikan data.

Automation

Mengotomatisasi pekerjaan yang dilakukan secara berulang.

Game Development

Membuat game sederhana menggunakan library seperti Pygame.

Cybersecurity

Membantu analisis keamanan dan pengujian sistem secara legal.

6. Program Python Pertama

Sekarang kita akan mencoba membuat program Python pertama. Program ini akan menampilkan beberapa kalimat sederhana menggunakan perintah print().

Perhatikan kode berikut:

print("Selamat Datang di Python!")
print("Saya Sedang Belajar Python")
print("Python Itu Menyenangkan!")

Hasil output:

Selamat Datang di Python!
Saya Sedang Belajar Python
Python Itu Menyenangkan!

Penjelasan:

  • print() merupakan fungsi bawaan Python untuk menampilkan informasi.
  • Teks yang ingin ditampilkan ditulis di antara tanda kutip.
  • Setiap perintah print() akan menampilkan output pada baris baru.
Praktikkan di Google Colab ↗

7. Aturan Dasar Penulisan Python

Dalam menulis kode Python, terdapat beberapa aturan dasar yang perlu diketahui.

A. Python Bersifat Case-Sensitive

Artinya, huruf besar dan huruf kecil dianggap berbeda. Perhatikan contoh berikut. 

nama = "Andi"
Nama = "Budi"

print(nama)
print(Nama)

Variabel nama dan Nama dianggap sebagai dua variabel yang berbeda.

B. Menggunakan Tanda Kutip untuk Teks

Teks atau string ditulis dengan menggunakan tanda kutip satu maupun tanda kutip dua. 

print("Belajar Python")
print('Pemrograman itu menyenangkan')

C. Menggunakan Indentasi

Indentasi adalah jarak atau spasi di awal baris kode. Python menggunakan indentasi untuk menentukan blok program. 

if 10 > 5:
    print("Sepuluh lebih besar dari lima")

Perhatikan bahwa perintah print() ditulis menjorok ke dalam. Indentasi tersebut menunjukkan bahwa perintah berada di dalam blok if.

D. Menggunakan Komentar

Komentar digunakan untuk memberikan keterangan pada kode dan tidak dijalankan sebagai perintah program. Komentar satu baris diawali dengan tanda pagar (#). 

# Ini adalah komentar
print("Hello Python")

8. Contoh Latihan Sederhana

Setelah memahami konsep dasar Python, sekarang cobalah membuat program sederhana untuk menampilkan biodata.

Contoh kode:

print("======================")
print("       BIODATA        ")
print("======================")
print("Nama    : Andi")
print("Umur    : 17 Tahun")
print("Hobi    : Membaca")
print("Alamat  : Jakarta")
print("======================")

Hasil output:

======================
       BIODATA
======================
Nama    : Andi
Umur    : 17 Tahun
Hobi    : Membaca
Alamat  : Jakarta
======================

Kamu bisa mengubah nama, umur, hobi, dan alamat sesuai data contoh yang diinginkan. Cobalah jalankan kode tersebut di Google Colab.
