Materi 5: Input dan Output Python

Dalam pemrograman, sebuah program tidak hanya perlu melakukan perhitungan, tetapi juga harus mampu berkomunikasi dengan penggunanya. Pada materi ini, kita akan mempelajari cara menerima data dari pengguna dan menampilkan informasi menggunakan Python.

Tujuan Pembelajaran Setelah mempelajari materi ini, kamu diharapkan mampu:
  1. Memahami konsep input dan output dalam Python.
  2. Menggunakan fungsi print() untuk menampilkan informasi.
  3. Menggunakan fungsi input() untuk menerima data.
  4. Mengubah tipe data input menggunakan fungsi konversi.
  5. Menggunakan f-string dan mengatur tampilan output.
  6. Membuat program sederhana yang interaktif.

1. Pengertian Input dan Output

Dalam pemrograman Python, Input dan Output merupakan dua hal penting yang digunakan untuk berkomunikasi dengan pengguna.

  • Input adalah proses memasukkan data ke dalam program.
  • Output adalah proses menampilkan hasil dari program kepada pengguna.

Dengan input dan output, program tidak hanya menjalankan perintah secara otomatis, tetapi juga dapat menerima informasi dari pengguna dan memberikan respons berdasarkan informasi tersebut.

Contoh sederhana proses input dan output:

  1. Pengguna memasukkan nama.
  2. Program menerima nama tersebut.
  3. Program menampilkan sapaan menggunakan nama yang dimasukkan.
Ingat! Input digunakan untuk menerima informasi, sedangkan output digunakan untuk menyampaikan informasi kepada pengguna.

2. Output Menggunakan print()

Fungsi print() digunakan untuk menampilkan teks, angka, variabel, maupun hasil perhitungan ke layar.

Contoh 1: Menampilkan teks

print("Halo, Selamat Belajar Python!")
Hasil Output: 
Halo, Selamat Belajar Python!

Contoh 2: Menampilkan angka

print(100)
print(25.5)
Hasil Output: 
100
25.5

Contoh 3: Menampilkan beberapa data

nama = "Andi"
umur = 17

print("Nama:", nama)
print("Umur:", umur)
Hasil Output: 
Nama: Andi
Umur: 17

Contoh 4: Menampilkan hasil operasi matematika

print(10 + 5)
print(20 * 3)
Hasil Output: 
15
60

Dari contoh tersebut, dapat diketahui bahwa fungsi print() dapat menampilkan berbagai jenis informasi, baik berupa teks, angka, variabel, maupun hasil operasi matematika.

3. Input Menggunakan input()

Fungsi input() digunakan untuk menerima data yang dimasukkan oleh pengguna melalui keyboard.

Catatan penting: Data yang dimasukkan menggunakan input() secara default akan dianggap sebagai tipe data string (str).

Contoh 1: Meminta nama pengguna

nama = input("Masukkan nama Anda: ")
print("Halo,", nama)
Contoh Interaksi Program: 
Masukkan nama Anda: Budi
Halo, Budi

Contoh 2: Meminta alamat pengguna

alamat = input("Masukkan alamat Anda: ")
print("Alamat Anda adalah:", alamat)
Contoh Interaksi: 
Masukkan alamat Anda: Jakarta
Alamat Anda adalah: Jakarta

Contoh 3: Meminta beberapa input

nama = input("Masukkan nama: ")
kelas = input("Masukkan kelas: ")
sekolah = input("Masukkan nama sekolah: ")

print("Nama:", nama)
print("Kelas:", kelas)
print("Sekolah:", sekolah)
Contoh Interaksi: 
Masukkan nama: Siti
Masukkan kelas: 10A
Masukkan nama sekolah: SMA Nusantara

Nama: Siti
Kelas: 10A
Sekolah: SMA Nusantara

Perhatikan bahwa program akan menunggu pengguna memasukkan data sebelum melanjutkan perintah berikutnya.

4. Mengubah Tipe Data Input

Secara default, fungsi input() menghasilkan data bertipe string. Jika ingin melakukan perhitungan matematika, kita perlu mengubah tipe data input menjadi angka.

Python menyediakan beberapa fungsi untuk mengubah tipe data:

Fungsi Kegunaan
int() Mengubah data menjadi bilangan bulat.
float() Mengubah data menjadi bilangan desimal.
str() Mengubah data menjadi teks.

Contoh 1: Menggunakan int()

umur = int(input("Masukkan umur Anda: "))

print("Umur Anda:", umur)
print("Tahun depan umur Anda:", umur + 1)
Contoh Interaksi: 
Masukkan umur Anda: 17
Umur Anda: 17
Tahun depan umur Anda: 18

Contoh 2: Menggunakan float()

tinggi = float(input("Masukkan tinggi badan: "))

print("Tinggi badan Anda:", tinggi)
Contoh Interaksi: 
Masukkan tinggi badan: 165.5
Tinggi badan Anda: 165.5

Contoh 3: Menggunakan str()

nomor = 12345
teks = str(nomor)

print("Nomor:", teks)
print("Tipe data:", type(teks))
Hasil Output: 
Nomor: 12345
Tipe data: <class 'str'>

Catatan Penting: Perbedaan String dan Angka

Perhatikan contoh berikut:

angka = input("Masukkan angka: ")
print(angka + angka)

Jika pengguna memasukkan angka 5, hasilnya adalah 55, bukan 10. Hal ini terjadi karena data masih berupa string sehingga tanda + digunakan untuk menggabungkan teks.

Agar bisa dijumlahkan sebagai angka, gunakan:

angka = int(input("Masukkan angka: "))
print(angka + angka)
Hasil Output (jika input adalah 5): 
10
Tips: Biasakan memeriksa tipe data input sebelum melakukan operasi matematika. Gunakan int() untuk bilangan bulat dan float() untuk bilangan desimal.

5. Menggabungkan Input dan Output

Input dan output dapat digabungkan untuk membuat program yang lebih interaktif. Salah satu contohnya adalah program biodata sederhana.

Contoh: Program Biodata Sederhana

print("=== PROGRAM BIODATA ===")

nama = input("Masukkan nama: ")
umur = int(input("Masukkan umur: "))
alamat = input("Masukkan alamat: ")
hobi = input("Masukkan hobi: ")

print("\n=== BIODATA ANDA ===")
print("Nama   :", nama)
print("Umur   :", umur, "tahun")
print("Alamat :", alamat)
print("Hobi   :", hobi)
Contoh Hasil Program: 
=== PROGRAM BIODATA ===
Masukkan nama: Andi
Masukkan umur: 17
Masukkan alamat: Bandung
Masukkan hobi: Membaca

=== BIODATA ANDA ===
Nama   : Andi
Umur   : 17 tahun
Alamat : Bandung
Hobi   : Membaca

Penjelasan program:

  1. print() menampilkan judul program.
  2. input() menerima nama, alamat, dan hobi.
  3. int() mengubah input umur menjadi bilangan bulat.
  4. Data disimpan dalam variabel masing-masing.
  5. print() menampilkan kembali biodata pengguna.

6. Menggunakan F-String untuk Output

F-string adalah cara praktis untuk memasukkan nilai variabel ke dalam teks.

Caranya adalah dengan menambahkan huruf f sebelum tanda kutip dan menempatkan variabel di dalam kurung kurawal {}.

Contoh 1: Menampilkan variabel

nama = "Andi"
umur = 17

print(f"Halo, nama saya {nama}.")
print(f"Saya berumur {umur} tahun.")
Hasil Output: 
Halo, nama saya Andi.
Saya berumur 17 tahun.

Contoh 2: F-string dengan operasi matematika

angka1 = 10
angka2 = 5

print(f"Hasil penjumlahan: {angka1 + angka2}")
Hasil Output: 
Hasil penjumlahan: 15

F-string sangat berguna ketika membuat tampilan program yang membutuhkan banyak variabel. Penulisan kode menjadi lebih ringkas dan mudah dibaca.

7. Mengatur Tampilan Output

Python menyediakan beberapa cara untuk mengatur tampilan teks yang dihasilkan. Berikut beberapa teknik yang perlu kamu ketahui.

A. Menggunakan sep

Parameter sep digunakan untuk mengatur pemisah antar-data pada fungsi print(). 

print("Belajar", "Python", "Mudah", sep="-")
Hasil Output: 
Belajar-Python-Mudah

B. Menggunakan end

Parameter end digunakan untuk mengatur karakter di akhir output. Secara default, fungsi print() menggunakan baris baru (\n). 

print("Halo", end=" ")
print("Dunia")
Hasil Output: 
Halo Dunia

C. Menggunakan karakter baris baru \n

Karakter \n digunakan untuk memindahkan teks ke baris berikutnya. 

print("Nama: Andi\nKelas: 10A\nHobi: Membaca")
Hasil Output: 
Nama: Andi
Kelas: 10A
Hobi: Membaca

D. Menggunakan tab \t

Karakter \t digunakan untuk memberikan jarak tab antar-teks. 

print("Nama\tUmur\tKelas")
print("Andi\t17\t10A")
Hasil Output: 
Nama    Umur    Kelas
Andi    17      10A
Rangkuman:
  • sep: mengatur pemisah antar-data.
  • end: mengatur karakter akhir output.
  • \n: membuat baris baru.
  • \t: memberikan jarak tab.

8. Contoh Project: Program Kalkulator Sederhana

Setelah memahami input dan output, sekarang kita akan membuat program kalkulator sederhana yang menerima dua angka dari pengguna.

Program ini akan melakukan operasi penjumlahan, pengurangan, perkalian, dan pembagian.

Kode Program

# Program Kalkulator Sederhana

print("=== KALKULATOR SEDERHANA ===")

angka1 = float(input("Masukkan angka pertama: "))
angka2 = float(input("Masukkan angka kedua: "))

penjumlahan = angka1 + angka2
pengurangan = angka1 - angka2
perkalian = angka1 * angka2

print("\n=== HASIL PERHITUNGAN ===")
print(f"Penjumlahan: {penjumlahan}")
print(f"Pengurangan: {pengurangan}")
print(f"Perkalian: {perkalian}")

if angka2 != 0:
    pembagian = angka1 / angka2
    print(f"Pembagian: {pembagian}")
else:
    print("Pembagian tidak dapat dilakukan dengan nol.")
Contoh Hasil Program: 
=== KALKULATOR SEDERHANA ===
Masukkan angka pertama: 20
Masukkan angka kedua: 5

=== HASIL PERHITUNGAN ===
Penjumlahan: 25.0
Pengurangan: 15.0
Perkalian: 100.0
Pembagian: 4.0

Penjelasan Program

  1. input() digunakan untuk menerima dua angka dari pengguna.
  2. float() mengubah input menjadi bilangan desimal.
  3. Variabel digunakan untuk menyimpan hasil perhitungan.
  4. print() menampilkan hasil perhitungan.
  5. if angka2 != 0 memastikan pembagian tidak dilakukan jika angka kedua bernilai nol.
Mengapa perlu menggunakan kondisi if? Dalam matematika, pembagian dengan nol tidak diperbolehkan. Oleh karena itu, program perlu memeriksa nilai angka kedua sebelum melakukan pembagian.

9. Kesalahan yang Sering Terjadi

Berikut beberapa kesalahan yang sering dilakukan pemula ketika menggunakan input dan output Python.

Kesalahan Penyebab Solusi
Hasil 5 + 5 menjadi 55 Input masih berupa string. Gunakan int() atau float().
ValueError Input tidak sesuai dengan tipe data yang diubah. Pastikan pengguna memasukkan angka.
NameError Variabel belum dibuat atau salah penulisan. Periksa nama variabel.
Output tidak sesuai Kesalahan penulisan kode. Periksa kembali perintah print().

Contoh Kesalahan: ValueError

umur = int(input("Masukkan umur: "))

Jika pengguna memasukkan teks seperti tujuh belas, Python akan menghasilkan ValueError karena teks tersebut tidak bisa langsung diubah menjadi bilangan bulat.

Tips menghindari kesalahan: Perhatikan jenis data yang dimasukkan pengguna. Jika program membutuhkan angka, pastikan input dikonversi ke tipe data numerik yang sesuai.
