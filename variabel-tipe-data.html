Materi 3: Variabel dan Tipe Data Python

Dalam pemrograman, kita sering berhadapan dengan berbagai macam informasi, seperti nama, umur, alamat, nilai, dan angka hasil perhitungan. Informasi tersebut perlu disimpan agar dapat digunakan kembali oleh program.

Python menyediakan konsep variabel dan tipe data untuk mengelola informasi tersebut. Pada materi ini, kita akan mempelajari cara membuat variabel, mengenali tipe data, mengubah tipe data, serta menggunakannya dalam program sederhana.

1. Pengertian Variabel

Variabel adalah tempat untuk menyimpan data atau nilai di dalam sebuah program. Variabel digunakan agar data dapat dipanggil, diubah, dan diolah kembali selama program berjalan.

Dalam Python, variabel dibuat dengan memberikan nama pada suatu nilai menggunakan tanda sama dengan (=). Tanda tersebut disebut operator assignment atau operator penugasan.

Contoh:

nama = "Andi"
umur = 17
nilai = 90

print(nama)
print(umur)
print(nilai)

Hasil Output:

Andi
17
90

Penjelasan:

  • nama merupakan variabel yang menyimpan data berupa teks.
  • umur merupakan variabel yang menyimpan data berupa angka.
  • nilai merupakan variabel yang menyimpan angka 90.
  • = merupakan operator assignment untuk memberikan nilai pada variabel.
  • print() digunakan untuk menampilkan nilai variabel.

Ilustrasi Variabel

Variabel dapat diibaratkan seperti wadah yang digunakan untuk menyimpan suatu nilai.

Variabel Nilai yang Disimpan
nama "Andi"
umur 17
nilai 90
Ingat!

Setiap variabel memiliki nama dan menyimpan nilai yang dapat digunakan oleh program. Nilai tersebut dapat berupa teks, angka, maupun jenis data lainnya.

2. Aturan Penamaan Variabel

Dalam Python, terdapat beberapa aturan yang harus diperhatikan ketika membuat nama variabel.

  1. Nama variabel harus diawali dengan huruf atau garis bawah (_).
  2. Nama variabel tidak boleh diawali dengan angka.
  3. Nama variabel tidak boleh mengandung spasi.
  4. Nama variabel hanya boleh menggunakan huruf, angka, dan garis bawah.
  5. Nama variabel tidak boleh menggunakan kata kunci khusus Python seperti if, for, while, dan class.
  6. Python membedakan huruf besar dan huruf kecil (case-sensitive).

Contoh Penamaan Variabel yang Benar

nama = "Budi"
umur = 17
nama_lengkap = "Budi Santoso"
_nilai = 90
nilai2 = 85

Contoh Penamaan Variabel yang Salah

# Diawali angka
2nama = "Budi"

# Mengandung spasi
nama lengkap = "Budi"

# Menggunakan kata kunci Python
class = "XI RPL"
Tips Penulisan Variabel

Gunakan nama variabel yang jelas dan mudah dipahami, misalnya nama_siswa, nilai_ujian, dan jumlah_barang.

Hindari penggunaan nama yang terlalu singkat jika membuat program menjadi sulit dipahami.

3. Mengubah Nilai Variabel

Nilai variabel dalam Python dapat diubah kapan saja selama program berjalan. Ketika nilai baru diberikan kepada variabel yang sama, nilai sebelumnya akan digantikan.

Contoh:

nama = "Andi"
print(nama)

nama = "Budi"
print(nama)

Hasil Output:

Andi
Budi

Pada contoh tersebut, nilai variabel nama awalnya adalah "Andi", kemudian diubah menjadi "Budi".

Variabel juga dapat digunakan dalam operasi matematika.

angka = 10
angka = angka + 5

print(angka)

Hasil Output:

15

Python menyediakan operator penugasan singkat, misalnya +=, -=, dan *=. 

angka = 10
angka += 5

print(angka)

Hasil Output:

15

Perintah angka += 5 memiliki arti yang sama dengan angka = angka + 5.

4. Pengertian Tipe Data

Tipe data (data type) adalah jenis atau kategori data yang disimpan dalam variabel. Setiap tipe data memiliki karakteristik dan kegunaan yang berbeda.

Python menyediakan berbagai tipe data untuk mengolah informasi dalam program. Empat tipe data dasar yang perlu dipahami oleh pemula adalah sebagai berikut.

Tipe Data Keterangan Contoh
String (str) Menyimpan data berupa teks. "Belajar Python"
Integer (int) Menyimpan bilangan bulat. 10, 25, 100
Float (float) Menyimpan bilangan desimal. 3.14, 10.5
Boolean (bool) Menyimpan nilai kebenaran. True, False
Perhatikan!

Python mengenali tipe data berdasarkan nilai yang diberikan. Misalnya, nilai "25" merupakan String karena menggunakan tanda kutip, sedangkan 25 merupakan Integer.

5. Jenis-Jenis Tipe Data Python

A. String (str)

String adalah tipe data yang digunakan untuk menyimpan teks atau kumpulan karakter. String ditulis menggunakan tanda kutip satu ('...') atau tanda kutip dua ("...").

Contoh:

nama = "Andi"
alamat = "Jakarta"
hobi = 'Membaca'

print(nama)
print(alamat)
print(hobi)

Hasil Output:

Andi
Jakarta
Membaca

String biasanya digunakan untuk menyimpan nama, alamat, kalimat, dan informasi berbentuk teks lainnya.

B. Integer (int)

Integer merupakan tipe data yang digunakan untuk menyimpan bilangan bulat, baik positif, negatif, maupun nol.

Contoh:

umur = 17
jumlah_siswa = 30
suhu = -5

print(umur)
print(jumlah_siswa)
print(suhu)

Hasil Output:

17
30
-5

Integer dapat digunakan dalam berbagai operasi matematika seperti penjumlahan, pengurangan, perkalian, dan pembagian.

C. Float (float)

Float merupakan tipe data yang digunakan untuk menyimpan bilangan desimal. Dalam Python, tanda titik (.) digunakan sebagai pemisah angka desimal.

Contoh:

harga = 15000.50
jarak = 12.5
nilai = 89.5

print(harga)
print(jarak)
print(nilai)

Hasil Output:

15000.5
12.5
89.5

D. Boolean (bool)

Boolean merupakan tipe data yang hanya memiliki dua kemungkinan nilai, yaitu True dan False.

Boolean biasanya digunakan dalam kondisi atau pengambilan keputusan pada program.

Contoh:

sudah_belajar = True
sudah_mengerjakan_tugas = False

print(sudah_belajar)
print(sudah_mengerjakan_tugas)

Hasil Output:

True
False

Contoh Penggunaan Boolean dalam Kondisi:

nilai = 85
lulus = nilai >= 75

print(lulus)

Hasil Output:

True

Hasil tersebut menunjukkan bahwa nilai 85 lebih besar atau sama dengan 75 sehingga variabel lulus bernilai True.

6. Mengenal Tipe Data dengan Fungsi type()

Python menyediakan fungsi bawaan type() untuk mengetahui tipe data dari sebuah variabel.

Contoh:

nama = "Andi"
umur = 17
tinggi = 170.5
aktif = True

print(type(nama))
print(type(umur))
print(type(tinggi))
print(type(aktif))

Hasil Output:

<class 'str'>
<class 'int'>
<class 'float'>
<class 'bool'>

Penjelasan:

  • type(nama) menghasilkan tipe data String.
  • type(umur) menghasilkan tipe data Integer.
  • type(tinggi) menghasilkan tipe data Float.
  • type(aktif) menghasilkan tipe data Boolean.
Coba Sendiri!

Buat variabel dengan nilai yang berbeda, kemudian gunakan type() untuk mengetahui tipe data masing-masing variabel.

7. Konversi Tipe Data (Type Casting)

Type Casting adalah proses mengubah suatu nilai dari satu tipe data ke tipe data lainnya. Python menyediakan beberapa fungsi untuk melakukan konversi tipe data.

Fungsi Kegunaan
str() Mengubah nilai menjadi String.
int() Mengubah nilai menjadi Integer.
float() Mengubah nilai menjadi Float.
bool() Mengubah nilai menjadi Boolean.

Contoh 1: Mengubah Integer menjadi String

umur = 17
umur_teks = str(umur)

print(umur_teks)
print(type(umur_teks))

Hasil Output:

17
<class 'str'>

Contoh 2: Mengubah String menjadi Integer

angka = "100"
hasil = int(angka)

print(hasil + 50)

Hasil Output:

150

Contoh 3: Mengubah Integer menjadi Float

angka = 10
hasil = float(angka)

print(hasil)

Hasil Output:

10.0
Catatan Penting

Tidak semua nilai dapat dikonversi. Misalnya, teks "Halo" tidak dapat langsung diubah menjadi Integer menggunakan int() karena bukan representasi bilangan bulat.

8. Menggabungkan Variabel dan Operasi Matematika

Variabel dapat digunakan untuk melakukan berbagai operasi matematika. Hasil operasi juga dapat disimpan ke dalam variabel lain.

Contoh:

angka1 = 20
angka2 = 10

penjumlahan = angka1 + angka2
pengurangan = angka1 - angka2
perkalian = angka1 * angka2
pembagian = angka1 / angka2

print("Penjumlahan:", penjumlahan)
print("Pengurangan:", pengurangan)
print("Perkalian:", perkalian)
print("Pembagian:", pembagian)

Hasil Output:

Penjumlahan: 30
Pengurangan: 10
Perkalian: 200
Pembagian: 2.0

Dari contoh tersebut, kita dapat melihat bahwa variabel memudahkan penyimpanan angka dan hasil perhitungan sehingga dapat digunakan kembali dalam program.

9. Membuat Beberapa Variabel Sekaligus

Python memungkinkan kita membuat beberapa variabel dalam satu baris. Teknik ini dikenal sebagai multiple assignment.

Contoh 1: Multiple Assignment

nama, kelas, jurusan = "Andi", "XI", "RPL"

print(nama)
print(kelas)
print(jurusan)

Hasil Output:

Andi
XI
RPL

Contoh 2: Memberikan Nilai yang Sama

a = b = c = 10

print(a)
print(b)
print(c)

Hasil Output:

10
10
10

Pada contoh pertama, beberapa variabel menerima nilai yang berbeda dalam satu baris. Pada contoh kedua, beberapa variabel menerima nilai yang sama.

13. Kesimpulan

Variabel dan tipe data merupakan konsep dasar yang sangat penting dalam pemrograman Python. Variabel digunakan untuk menyimpan data, sedangkan tipe data menentukan jenis nilai yang disimpan.

Python memiliki berbagai tipe data, di antaranya String (str), Integer (int), Float (float), dan Boolean (bool). Kita dapat mengetahui tipe data menggunakan fungsi type() serta mengubah tipe data menggunakan fungsi seperti str(), int(), float(), dan bool().
