Materi 6: Percabangan Python (If, Elif, dan Else)

Dalam pemrograman, program sering kali perlu mengambil keputusan berdasarkan kondisi tertentu. Misalnya, menentukan apakah seorang siswa lulus atau tidak, apakah suatu angka termasuk ganjil atau genap, dan menentukan predikat berdasarkan nilai.

Pada materi ini, kita akan mempelajari bagaimana menggunakan percabangan dalam Python agar program dapat mengambil keputusan secara otomatis.

Tujuan Pembelajaran Setelah mempelajari materi ini, kamu diharapkan mampu:
  1. Memahami konsep dan fungsi percabangan.
  2. Menggunakan perintah if, elif, dan else.
  3. Menggunakan operator perbandingan dalam kondisi.
  4. Menggabungkan beberapa kondisi dengan operator logika.
  5. Menggunakan percabangan bersarang (nested if).
  6. Membuat program sederhana menggunakan percabangan.

1. Pengertian Percabangan

Percabangan adalah salah satu konsep dasar dalam pemrograman yang digunakan untuk membuat keputusan berdasarkan kondisi tertentu.

Dengan percabangan, program dapat menjalankan perintah yang berbeda sesuai dengan kondisi yang terpenuhi.

Contoh penerapan percabangan dalam kehidupan sehari-hari:

  • Jika hujan, maka membawa payung.
  • Jika nilai ujian lebih dari atau sama dengan 75, maka dinyatakan lulus.
  • Jika saldo mencukupi, maka transaksi dapat dilakukan.
  • Jika usia memenuhi ketentuan, maka pengguna dapat melanjutkan proses.

Dalam Python, percabangan menggunakan beberapa perintah berikut:

Perintah Fungsi
if Menjalankan kode jika kondisi benar.
elif Memeriksa kondisi tambahan jika kondisi sebelumnya salah.
else Menjalankan kode jika semua kondisi sebelumnya salah.
Konsep Dasar: Percabangan bekerja dengan memeriksa suatu kondisi. Jika kondisi bernilai True, program menjalankan perintah yang sesuai. Jika bernilai False, program akan memilih jalur perintah lainnya jika tersedia.

2. Percabangan if

if merupakan bentuk percabangan paling sederhana dalam Python. Perintah ini digunakan untuk menjalankan kode hanya ketika suatu kondisi bernilai True (benar).

Sintaks Dasar

if kondisi:
    perintah

Contoh penggunaan:

umur = 18

if umur >= 17:
    print("Anda sudah cukup umur.")
Hasil Output: 
Anda sudah cukup umur.

Penjelasan

  1. Variabel umur memiliki nilai 18.
  2. Python memeriksa apakah umur >= 17.
  3. Karena kondisi bernilai benar (True), perintah print() dijalankan.

Contoh Ketika Kondisi Salah

umur = 15

if umur >= 17:
    print("Anda sudah cukup umur.")
Hasil Output: 
(Tidak ada output)

Tidak ada output karena kondisi umur >= 17 bernilai False. Perintah di dalam blok if tidak dijalankan.

Perhatikan: Setiap pernyataan if diakhiri dengan tanda titik dua (:). Perintah yang termasuk ke dalam blok if harus ditulis dengan indentasi.

3. Percabangan if-else

if-else digunakan ketika program memiliki dua kemungkinan hasil:

  • Jika kondisi benar, jalankan perintah if.
  • Jika kondisi salah, jalankan perintah else.

Sintaks Dasar

if kondisi:
    perintah_jika_benar
else:
    perintah_jika_salah

Contoh 1: Menentukan Kelulusan

nilai = 80

if nilai >= 75:
    print("Selamat, Anda lulus!")
else:
    print("Maaf, Anda belum lulus.")
Hasil Output: 
Selamat, Anda lulus!

Contoh 2: Nilai Belum Memenuhi Kriteria

nilai = 60

if nilai >= 75:
    print("Selamat, Anda lulus!")
else:
    print("Maaf, Anda belum lulus.")
Hasil Output: 
Maaf, Anda belum lulus.

Penjelasan

Python memeriksa nilai variabel nilai. Jika nilainya minimal 75, program menampilkan pesan lulus. Jika kurang dari 75, program menampilkan pesan belum lulus.

Dengan demikian, if-else memungkinkan program memilih salah satu dari dua kemungkinan perintah berdasarkan kondisi yang diperiksa.

4. Percabangan if-elif-else

Percabangan if-elif-else digunakan ketika program memiliki lebih dari dua kemungkinan kondisi.

elif merupakan singkatan dari else if, yaitu kondisi tambahan yang diperiksa jika kondisi sebelumnya tidak terpenuhi.

Sintaks Dasar

if kondisi_1:
    perintah_1
elif kondisi_2:
    perintah_2
elif kondisi_3:
    perintah_3
else:
    perintah_lain

Contoh: Menentukan Predikat Nilai

nilai = 85

if nilai >= 90:
    print("Predikat A")
elif nilai >= 80:
    print("Predikat B")
elif nilai >= 70:
    print("Predikat C")
else:
    print("Predikat D")
Hasil Output: 
Predikat B

Penjelasan

  1. Python memeriksa apakah nilai minimal 90. Hasilnya salah.
  2. Python memeriksa apakah nilai minimal 80. Hasilnya benar.
  3. Program menampilkan Predikat B.
  4. Kondisi berikutnya tidak perlu diperiksa lagi.
Catatan Penting: Python akan menjalankan blok pertama yang kondisinya bernilai True dalam rangkaian if-elif-else. Karena itu, urutan kondisi harus diperhatikan.

Ilustrasi Urutan Pemeriksaan Kondisi

nilai = 85

if nilai >= 90:
    print("A")
elif nilai >= 80:
    print("B")
elif nilai >= 70:
    print("C")
else:
    print("D")

Karena nilai 85 memenuhi kondisi kedua, program langsung menampilkan predikat B. Kondisi ketiga dan blok else tidak dijalankan.

5. Mengenal Operator Perbandingan

Percabangan menggunakan operator perbandingan untuk memeriksa apakah suatu kondisi benar atau salah.

Berikut operator perbandingan dalam Python:

Operator Arti Contoh
== Sama dengan a == b
!= Tidak sama dengan a != b
> Lebih besar dari a > b
< Lebih kecil dari a < b
>= Lebih besar atau sama dengan a >= b
<= Lebih kecil atau sama dengan a <= b

Contoh Penggunaan

a = 10
b = 5

print(a == b)
print(a != b)
print(a > b)
print(a < b)
Hasil Output: 
False
True
True
False

Operator perbandingan menghasilkan nilai Boolean, yaitu True atau False. Nilai inilah yang digunakan Python untuk menentukan apakah suatu blok percabangan dijalankan.

6. Mengenal Operator Logika

Selain operator perbandingan, Python juga memiliki operator logika yang dapat digunakan untuk menggabungkan beberapa kondisi.

Terdapat tiga operator logika utama:

Operator Fungsi
and Benar jika semua kondisi benar.
or Benar jika minimal satu kondisi benar.
not Membalik nilai kebenaran.

A. Operator and

Operator and menghasilkan nilai True jika semua kondisi bernilai benar. 

umur = 20
punya_ktp = True

if umur >= 17 and punya_ktp:
    print("Persyaratan terpenuhi.")
else:
    print("Persyaratan belum terpenuhi.")
Hasil Output: 
Persyaratan terpenuhi.

B. Operator or

Operator or menghasilkan nilai True jika minimal satu kondisi benar. 

hari = "Minggu"

if hari == "Sabtu" or hari == "Minggu":
    print("Hari libur.")
else:
    print("Hari kerja.")
Hasil Output: 
Hari libur.

C. Operator not

Operator not digunakan untuk membalik nilai kondisi. Jika kondisi bernilai True, hasilnya menjadi False, begitu juga sebaliknya. 

hujan = False

if not hujan:
    print("Tidak perlu membawa payung.")
else:
    print("Bawa payung.")
Hasil Output: 
Tidak perlu membawa payung.

Tabel Kebenaran Operator Logika

A B A and B A or B
True True True True
True False False True
False True False True
False False False False

Operator not memiliki tabel kebenaran berikut:

A not A
True False
False True

7. Percabangan Bersarang (Nested If)

Nested if adalah percabangan yang berada di dalam percabangan lainnya.

Teknik ini berguna ketika suatu kondisi perlu diperiksa lagi setelah kondisi sebelumnya terpenuhi.

Contoh: Pemeriksaan Usia dan Tiket

umur = 20
memiliki_tiket = True

if umur >= 17:
    if memiliki_tiket:
        print("Silakan masuk.")
    else:
        print("Anda harus memiliki tiket.")
else:
    print("Usia belum memenuhi ketentuan.")
Hasil Output: 
Silakan masuk.

Penjelasan

  1. Program memeriksa apakah umur minimal 17 tahun.
  2. Jika benar, program memeriksa apakah pengguna memiliki tiket.
  3. Jika kedua kondisi terpenuhi, program menampilkan pesan bahwa pengguna boleh masuk.

Perhatikan bahwa terdapat dua tingkat percabangan. Kondisi kedua hanya diperiksa jika kondisi pertama terpenuhi.

Perhatikan Indentasi: Pada nested if, setiap tingkat percabangan memiliki indentasi tersendiri. Pastikan jarak indentasi ditulis secara konsisten.

8. Contoh Project: Program Penilaian Siswa

Sekarang kita akan membuat program sederhana untuk menentukan predikat nilai siswa menggunakan percabangan.

Kode Program

# Program Penilaian Siswa

print("=== PROGRAM PENILAIAN SISWA ===")

nama = input("Masukkan nama siswa: ")
nilai = int(input("Masukkan nilai: "))

print("\n=== HASIL PENILAIAN ===")
print("Nama:", nama)
print("Nilai:", nilai)

if nilai < 0 or nilai > 100:
    print("Nilai tidak valid.")
elif nilai >= 90:
    print("Predikat: A")
    print("Keterangan: Sangat Baik")
elif nilai >= 80:
    print("Predikat: B")
    print("Keterangan: Baik")
elif nilai >= 70:
    print("Predikat: C")
    print("Keterangan: Cukup")
elif nilai >= 60:
    print("Predikat: D")
    print("Keterangan: Kurang")
else:
    print("Predikat: E")
    print("Keterangan: Perlu Belajar Lagi")
Contoh Hasil Program: 
=== PROGRAM PENILAIAN SISWA ===
Masukkan nama siswa: Andi
Masukkan nilai: 85

=== HASIL PENILAIAN ===
Nama: Andi
Nilai: 85
Predikat: B
Keterangan: Baik

Penjelasan Program

  1. Program meminta nama dan nilai siswa.
  2. Nilai diperiksa terlebih dahulu untuk memastikan berada pada rentang 0–100.
  3. Jika nilai minimal 90, siswa mendapat predikat A.
  4. Jika nilai minimal 80, siswa mendapat predikat B.
  5. Jika nilai minimal 70, siswa mendapat predikat C.
  6. Jika nilai minimal 60, siswa mendapat predikat D.
  7. Jika tidak memenuhi kondisi sebelumnya, siswa mendapat predikat E.
Hal yang perlu diperhatikan: Program memeriksa rentang nilai terlebih dahulu. Dengan demikian, nilai di bawah 0 atau di atas 100 tidak akan dianggap sebagai nilai yang valid.

9. Contoh Project: Program Menentukan Bilangan Ganjil atau Genap

Program ini digunakan untuk menentukan apakah sebuah angka termasuk bilangan ganjil atau genap.

Kode Program

# Program Menentukan Bilangan Ganjil atau Genap

angka = int(input("Masukkan sebuah angka: "))

if angka % 2 == 0:
    print("Bilangan Genap")
else:
    print("Bilangan Ganjil")
Contoh Hasil Pertama: 
Masukkan sebuah angka: 10
Bilangan Genap
Contoh Hasil Kedua: 
Masukkan sebuah angka: 7
Bilangan Ganjil

Penjelasan

  • Operator % digunakan untuk mendapatkan sisa hasil bagi.
  • Jika angka dibagi 2 menghasilkan sisa 0, maka termasuk bilangan genap.
  • Jika sisanya bukan 0, maka termasuk bilangan ganjil.
Contoh:
  • 10 % 2 = 0, sehingga 10 adalah bilangan genap.
  • 7 % 2 = 1, sehingga 7 adalah bilangan ganjil.

10. Kesalahan yang Sering Terjadi

Saat belajar percabangan, pemula sering melakukan beberapa kesalahan berikut:

Kesalahan Penyebab Solusi
SyntaxError Penulisan sintaks salah. Periksa tanda titik dua dan penulisan perintah.
IndentationError Jarak indentasi tidak konsisten. Gunakan indentasi yang konsisten.
Kondisi tidak berjalan Operator perbandingan salah. Periksa operator yang digunakan.
Hasil kondisi tidak sesuai Urutan kondisi kurang tepat. Susun kondisi berdasarkan rentang yang sesuai.
TypeError Tipe data tidak sesuai. Periksa dan sesuaikan tipe data.

Contoh Kesalahan Indentasi

Kode yang salah:

nilai = 80

if nilai >= 75:
print("Anda lulus")

Kode yang benar:

nilai = 80

if nilai >= 75:
    print("Anda lulus")

Perhatikan bahwa perintah di dalam blok if harus memiliki indentasi. Pada Python, indentasi digunakan untuk menunjukkan bagian kode yang termasuk dalam suatu blok perintah.

Tips: Biasakan menggunakan empat spasi untuk setiap tingkat indentasi. Jangan mencampurkan tab dan spasi secara tidak konsisten.

Ketentuan Tugas:

  1. Program meminta nama lengkap siswa.
  2. Program meminta kelas siswa.
  3. Program meminta nilai mata pelajaran.
  4. Program memeriksa apakah nilai berada pada rentang 0 sampai 100.

  7. Gunakan print() atau f-string untuk menampilkan hasil dengan rapi.
