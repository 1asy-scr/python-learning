Materi 2: Mengenal Google Colab

Pada materi sebelumnya, kita telah mengenal bahasa pemrograman Python, sejarah perkembangannya, serta contoh program sederhana. Selanjutnya, kita akan mempelajari salah satu alat yang dapat digunakan untuk menulis dan menjalankan kode Python, yaitu Google Colab.

Google Colab akan menjadi lingkungan praktik utama dalam pembelajaran Python ini. Dengan Google Colab, kita dapat menulis dan menjalankan program Python secara langsung melalui browser tanpa harus memasang Python di komputer.

1. Apa Itu Google Colab?

Google Colaboratory atau lebih dikenal dengan Google Colab adalah layanan berbasis cloud yang disediakan oleh Google untuk menulis, menjalankan, dan membagikan kode program Python melalui browser.

Google Colab menyediakan lingkungan pemrograman interaktif yang disebut notebook. Di dalam notebook, pengguna dapat menuliskan kode Python, menjalankannya, melihat hasilnya, serta menambahkan teks atau penjelasan.

Informasi Penting

Google Colab dapat digunakan secara gratis dengan akun Google. Pengguna tidak perlu melakukan instalasi Python terlebih dahulu untuk mulai belajar dan menjalankan program.

Untuk mulai menggunakan Google Colab, kunjungi situs resminya melalui tautan berikut:

Buka Google Colab

2. Fungsi dan Kegunaan Google Colab

Google Colab memiliki berbagai fungsi yang mendukung kegiatan pemrograman, pembelajaran, dan pengolahan data. Beberapa kegunaannya adalah sebagai berikut.

  1. Menulis kode Python. Google Colab menyediakan area kerja untuk menuliskan instruksi atau kode program Python.
  2. Menjalankan program. Kode yang ditulis dapat dijalankan secara langsung dan hasilnya ditampilkan pada notebook.
  3. Belajar pemrograman. Pengguna dapat mencoba berbagai contoh program Python tanpa perlu memasang perangkat lunak tambahan.
  4. Pengolahan data. Google Colab dapat digunakan untuk membaca, mengolah, dan menganalisis data.
  5. Membuat visualisasi. Pengguna dapat membuat grafik dan visualisasi data menggunakan berbagai library Python.
  6. Berbagi pekerjaan. Notebook dapat dibagikan kepada orang lain melalui tautan, seperti ketika membagikan dokumen Google Drive.

3. Kelebihan Google Colab

Google Colab memiliki sejumlah kelebihan yang membuatnya cocok digunakan sebagai sarana belajar Python, khususnya bagi pemula.

  • Gratis untuk penggunaan dasar. Pengguna dapat memanfaatkan layanan dasar Google Colab tanpa harus membayar.
  • Tidak perlu instalasi. Python dan berbagai library umum telah tersedia dalam lingkungan kerja Colab.
  • Dapat diakses melalui browser. Pengguna dapat belajar menggunakan komputer yang terhubung dengan internet.
  • Terintegrasi dengan Google Drive. Notebook dapat disimpan dan dikelola melalui Google Drive.
  • Mendukung pembelajaran interaktif. Kode dan penjelasan dapat ditulis dalam satu dokumen.
  • Mudah dibagikan. Notebook dapat dibagikan kepada teman atau pengajar.
Catatan

Ketersediaan sumber daya komputasi pada Google Colab dapat berubah sesuai kebijakan dan kapasitas layanan.

4. Kekurangan Google Colab

Meskipun memiliki banyak kelebihan, Google Colab juga mempunyai beberapa keterbatasan yang perlu diketahui.

  • Membutuhkan koneksi internet. Pengguna memerlukan koneksi internet untuk mengakses dan menjalankan notebook.
  • Memiliki batas penggunaan. Sumber daya komputasi dan durasi penggunaan dapat dibatasi oleh layanan.
  • Lingkungan kerja dapat terputus. Sesi kerja dapat berakhir sehingga pengguna perlu menjalankan kembali kode ketika membuka sesi baru.
  • File sementara dapat hilang. File yang disimpan pada penyimpanan sementara mesin virtual tidak selalu tersedia setelah sesi berakhir.
  • Bergantung pada layanan Google. Pengguna perlu mengikuti ketentuan dan ketersediaan layanan Google Colab.
Saran Belajar

Biasakan menyimpan notebook di Google Drive dan mengunduh salinan pekerjaan penting agar hasil latihan tidak mudah hilang.

5. Mengenal Tampilan Google Colab

Sebelum menulis kode, kita perlu mengenal beberapa bagian utama yang terdapat pada halaman Google Colab.

  1. Nama Notebook. Menunjukkan nama dokumen atau file notebook yang sedang dibuka. Nama notebook dapat diubah sesuai kebutuhan.
  2. Menu Bar. Berisi menu seperti File, Edit, View, Insert, Runtime, Tools, dan Help.
  3. Toolbar. Berisi tombol untuk menambahkan cell, menjalankan kode, dan melakukan beberapa pengaturan.
  4. Code Cell. Area untuk menuliskan kode Python.
  5. Output Cell. Area untuk menampilkan hasil dari kode yang dijalankan.
  6. Runtime. Lingkungan komputasi yang digunakan untuk menjalankan kode program.
Perhatikan!

Pada Google Colab, kode tidak langsung dijalankan ketika ditulis. Kita perlu menekan tombol Run atau menggunakan kombinasi tombol tertentu untuk menjalankannya.

6. Cara Menggunakan Google Colab

Berikut langkah-langkah untuk mulai menggunakan Google Colab.

  1. Buka browser pada komputer atau laptop.
  2. Kunjungi https://colab.research.google.com/ .
  3. Masuk menggunakan akun Google jika diminta.
  4. Pada halaman awal Google Colab, pilih menu New Notebook untuk membuat notebook baru.
  5. Setelah notebook terbuka, klik area Code Cell untuk mulai menulis kode Python.
  6. Tuliskan kode Python yang ingin dijalankan.
  7. Klik tombol Run atau tekan Shift + Enter.
  8. Perhatikan hasil yang muncul di bawah Code Cell.
Praktik Sekarang

Klik tombol berikut untuk membuka Google Colab dan membuat notebook baru.

Buka Notebook Baru

7. Mengenal Jenis Cell di Google Colab

Cell merupakan bagian atau area kerja dalam notebook. Google Colab menyediakan dua jenis cell utama yang perlu kita kenali.

A. Code Cell

Code Cell digunakan untuk menuliskan dan menjalankan kode Python. 

print("Selamat belajar Python!")
print("Saya menggunakan Google Colab.")

Output:

Selamat belajar Python!
Saya menggunakan Google Colab.

B. Text Cell

Text Cell digunakan untuk menuliskan penjelasan, catatan, judul, atau dokumentasi dalam notebook. Text Cell mendukung format Markdown.

Contoh isi Text Cell:

# Belajar Python
## Materi 2: Google Colab

Pada notebook ini saya belajar
menjalankan program Python.
Perbedaan Utama

Code Cell digunakan untuk menjalankan instruksi Python, sedangkan Text Cell digunakan untuk memberikan penjelasan atau informasi.

8. Menjalankan Beberapa Code Cell

Dalam satu notebook, kita dapat membuat beberapa Code Cell. Setiap cell dapat berisi kode yang berbeda dan dijalankan secara terpisah.

Contoh Code Cell 1:

nama = "Andi"
print(nama)

Output:

Andi

Contoh Code Cell 2:

umur = 18
print(umur)

Output:

18

Contoh Code Cell 3:

print("Nama saya", nama)
print("Umur saya", umur, "tahun")

Output:

Nama saya Andi
Umur saya 18 tahun

Contoh tersebut menunjukkan bahwa variabel yang dibuat pada satu cell dapat digunakan pada cell berikutnya selama masih berada dalam sesi runtime yang sama.

Hal yang Perlu Diperhatikan

Urutan menjalankan cell dapat memengaruhi hasil program. Jika sebuah variabel belum dibuat, kemudian digunakan pada cell lain, Python dapat menampilkan pesan kesalahan.

9. Menggunakan Library Python di Google Colab

Library adalah kumpulan kode atau fungsi yang dapat digunakan untuk membantu menyelesaikan berbagai pekerjaan pemrograman. Dengan library, kita tidak perlu membuat semua fungsi dari awal.

Google Colab telah menyediakan sejumlah library Python yang umum digunakan. Kita dapat memanggilnya menggunakan perintah import.

Contoh Menggunakan Library Math

import math

angka = 25
hasil = math.sqrt(angka)

print("Akar dari", angka, "adalah", hasil)

Output:

Akar dari 25 adalah 5.0

Pada contoh tersebut, kita menggunakan library math untuk menghitung akar kuadrat menggunakan fungsi sqrt().

Contoh Menggunakan Library Random

import random

angka = random.randint(1, 10)

print("Angka yang diperoleh:", angka)

Program tersebut menghasilkan bilangan acak antara 1 sampai 10.

Catatan

Tidak semua library tersedia secara otomatis. Library tertentu dapat dipasang menggunakan perintah !pip install nama_library. Namun, untuk materi dasar ini kita akan menggunakan library yang sudah tersedia.

10. Menyimpan dan Mengunduh Notebook

Notebook yang dibuat di Google Colab perlu disimpan agar pekerjaan dapat dibuka dan dilanjutkan kembali. Secara umum, Google Colab dapat menyimpan notebook ke Google Drive.

A. Menyimpan Notebook

  1. Buka notebook yang sedang dikerjakan.
  2. Klik nama notebook untuk mengubah namanya.
  3. Berikan nama yang sesuai dengan materi atau kegiatan yang dikerjakan.
  4. Notebook dapat disimpan ke Google Drive melalui menu File jika diperlukan.

B. Mengunduh Notebook

  1. Klik menu File.
  2. Pilih menu Download.
  3. Pilih Download .ipynb.
  4. File notebook akan diunduh ke perangkat dengan format .ipynb.
Tips

Gunakan nama file yang jelas, misalnya Tugas2_GoogleColab_Nama.ipynb. Dengan demikian, file lebih mudah ditemukan dan dikenali ketika dikumpulkan.

11. Praktik Langsung: Membuat Program Biodata

Setelah mengenal fitur dasar Google Colab, sekarang kita akan mencoba membuat program sederhana untuk menampilkan biodata. Praktik ini bertujuan agar kita terbiasa menulis dan menjalankan kode Python di dalam Code Cell.

Langkah 1: Buat Notebook Baru

Buka Google Colab, kemudian pilih New Notebook.

Langkah 2: Masukkan Kode Program

Tuliskan kode berikut pada Code Cell.

# Program Biodata Sederhana

nama = "Andi"
tempat_lahir = "Bandung"
umur = 18
hobi = "Membaca"

print("BIODATA DIRI")
print("====================")
print("Nama          :", nama)
print("Tempat Lahir  :", tempat_lahir)
print("Umur          :", umur, "tahun")
print("Hobi          :", hobi)

Langkah 3: Jalankan Program

Tekan tombol Run atau gunakan kombinasi Shift + Enter.

Hasil Program

BIODATA DIRI
====================
Nama          : Andi
Tempat Lahir  : Bandung
Umur          : 18 tahun
Hobi          : Membaca

Langkah 4: Modifikasi Program

Ubah nilai variabel pada program tersebut menggunakan biodata masing-masing. Jalankan kembali program dan amati hasilnya.

13. Kesimpulan

Google Colab merupakan layanan berbasis cloud yang memudahkan pengguna untuk menulis, menjalankan, dan membagikan program Python melalui browser. Layanan ini sangat membantu pemula karena tidak memerlukan instalasi Python secara manual.

Dalam Google Colab, pengguna dapat membuat notebook yang terdiri atas Code Cell dan Text Cell. Kode Python dapat dijalankan menggunakan tombol Run atau kombinasi Shift + Enter. Notebook juga dapat disimpan di Google Drive dan diunduh dalam format .ipynb.

Tugas 2: Membuat dan Mengumpulkan Notebook Google Colab

Setelah mempelajari materi ini, kerjakan tugas berikut secara mandiri.

Petunjuk Pengerjaan

  1. Buka Google Colab dan buat sebuah notebook baru.
  2. Berikan nama notebook: Tugas2_Nama.
  3. Buat satu Text Cell yang berisi judul "Praktik Google Colab" dan identitas diri.
  4. Buat Code Cell untuk menampilkan biodata menggunakan perintah print().
  5. Buat Code Cell kedua untuk melakukan perhitungan sederhana, misalnya penjumlahan, pengurangan, perkalian, dan pembagian.
  6. Pastikan seluruh kode berhasil dijalankan dan hasilnya terlihat.

Ketentuan Pengumpulan

  • Pastikan nama file mencantumkan nama Anda.
  • Pastikan notebook dapat dibuka dan dijalankan.
  • Kumpulkan file sesuai petunjuk pengumpulan tugas.
Perhatian

Pengumpulan tugas dilakukan melalui tombol Pengumpulan Tugas pada sidebar. Pastikan file notebook sudah disiapkan sebelum melakukan pengumpulan.
